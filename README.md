# Breast Cancer Classification

A machine learning project that classifies breast tumors as malignant or benign using Logistic Regression on the Wisconsin Breast Cancer Diagnostic dataset.

## Features

- **Data Processing**: Uses `pandas` and `scikit-learn` to clean and prepare the dataset.
- **Model Training**: Implements a Logistic Regression model for binary classification.
- **Evaluation**: Calculates accuracy scores for both training and testing datasets.

## Technical Details

- **Dataset**: `sklearn.datasets.load_breast_cancer()`
- **Libraries**: `numpy`, `pandas`, `scikit-learn`
- **Model**: Logistic Regression (Regularized)

## Installation & Usage

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   cd breast-cancer-classification
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Open the notebook:
   ```bash
   jupyter notebook Breast_Cancer_Classification.ipynb
   ```
